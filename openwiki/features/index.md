# Files

- [AI Improvement Suggestions](ai_improvement_suggestions.md) - Feature that generates AI-powered suggestions for improving CVs based on job description analysis.
- [AI Rebuild CV](ai_rebuild_cv.md) - Feature that converts uploaded CVs (PDF/DOCX) into standardized PDF format using AI for data extraction and headless Chromium for PDF generation.
- [Application Tracker](application_tracker.md) - Feature that allows students to track their job applications and status changes.
- [CV & JD Match Analyzer](cv_jd_match_analyzer.md) - Feature that analyzes CVs against job descriptions using AI to compute match scores and provide evidence-based feedback.
- [Job Post Management API](job_post_management.md) - API endpoints for managing job postings, including creation, publishing, archiving, and scoring configuration.
- [Recruiter Pipeline and Candidate Email](recruiter_pipeline_email.md) - Feature that enables recruiters to manage application pipelines and send automated emails to candidates.
